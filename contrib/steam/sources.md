# The Steam copy's library source

[The Steam copy](README.md) › The libraries' source. Also: [how the Linux depot works](linux-depot.md).

Most of the bundled libraries are under the LGPL or the GPL, which ask whoever ships them to make their source available. Each release with a Steam build does that itself: `fetch-sources.py` reads the depot's `share/licenses/PACKAGES.txt`, downloads the Ubuntu source package (the `.dsc` and the tarballs it names) of every package listed there, at exactly that version, and packs them into `upnext-steam-linux-sources.tar` with a `MANIFEST.txt` of every package, version and file with its SHA-256. The release workflow attaches that tar and its `.sha256` to the release, and `PACKAGES.txt` names it with its address on that release (`bundle-linux.py` takes the version from `bin/upnext --version`). It holds every bundled package's source, not only the LGPL and GPL ones, so no licence has to be judged one package at a time; for a release made on Ubuntu 22.04 that's about 80 source packages and 430 MB, a fifth of it GCC's source, for `libatomic`. The tar stays out of the depot, which it would more than double.

`fetch-sources.py` runs on the machine that made the depot, as any user: it gives apt source lists of its own for that Ubuntu release, so the computer's apt settings are neither needed nor changed, and apt checks every file against the archive's signed index. A version the archive no longer lists, because a newer update replaced it, comes from Launchpad instead, which keeps every version Ubuntu published. That route is weaker, and `MANIFEST.txt` marks the packages that took it: the `.dsc` is taken as Launchpad serves it over HTTPS, with no signature checked, and the other files are checked against its SHA-256 and its `Source` and `Version` against the package asked for. That catches a damaged, cut-off or mismatched download, but not a forged `.dsc` served with matching forged files, by Launchpad itself or by someone who can intercept its TLS. Every source package name and version from `PACKAGES.txt` must have Debian's form before it becomes a folder name or reaches apt. `fetch-sources.py --self-test` runs the Launchpad route and those checks against a made-up package on a local server, with no network.
